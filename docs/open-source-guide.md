Three sections are excerpted. Markdown emphasis, bullet markers and paragraph spacing are simplified; selected passages are joined. Section titles and English/Hindi starter explanations are Pass It On adaptations. They are not official GitHub translations or endorsements. Links, attribution, license, source-check date and pinned revision are visible in the workspace; downloaded answers include source attribution and the return link.

Prepared starter answers are immediately readable without AI credits or a wallet. They are explicitly labelled and are not stored or counted as volunteer reviews. ElevenLabs reads them from server-owned text. Volunteer contributions still go through Gemini source checks and the labelled demo review role before sharing through Snowflake. A guide starter or reading token cannot authorize a payment.

## Collection boundaries

`/app` opens the real collection. Links use `collection=open-source` and a question such as `oss-non-code`. Real endpoints are under `/api/passiton/guides/open-source`.

The original `/api/passiton` endpoints and source hash remain intact. Old links for `provisional`, `documents` and `submission` resolve to the practice collection. Its existing local storage, published answers and devnet receipt remain accessible. Each collection uses its own browser storage key and source version. A source update invalidates approvals in that collection only.

Coverage binds the selected question IDs as JSON and the selected source version as SQL values. It needs no new tables or broader Snowflake permissions. Prepared starter answers never inflate reviewed counts.

## Limits

The source is real; the reviewer identity system is still a demo role. This collection gives general open-source contribution guidance, not project-specific permission or a guarantee a contribution will be accepted. Visitors should read the target project's own contribution instructions. A real organizational publishing workflow still needs authenticated maintainers, corrections/removal and durable abuse controls.
